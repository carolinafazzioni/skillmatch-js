# SkillMatch

Projeto desenvolvido em JavaScript puro para cadastrar candidatos, cadastrar vagas e verificar compatibilidade entre eles.

## Descrição

O SkillMatch é um projeto desenvolvido durante a sexta semana de aulas do curso de Desenvolvimento de Software Front-End React do projeto SCTech. O projeto é entitulado "SkillMatch JS: Simulador de Compatibilidade com Vaga Front-End Júnior". O projeto é desenvolvido em JavaScript que permite cadastrar candidatos e vagas de emprego, permitindo analisar a compatibilidade das vagas com as habilidades dos candidatos.

## Tecnologias Utilizadas 

- JavaScript
- Git
- GitHub

## Funcionalidades

- Criar perfil de candidatos;
- Criar vagas de emprego front-end;
- Crusar perfil candidato com vaga pretendida;
